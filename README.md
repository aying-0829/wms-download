## 三步上线

1. **下载安装** — 解压 `WMS-Setup.zip`，右键 `install.bat` 以管理员身份运行，全自动完成。
2. **自动试用** — 浏览器打开 `http://本机IP:8000`，账号 `admin` / `Admin@123456`（首次登录请改密），自动进入 **30 天全功能试用**，无需注册、无需留联系方式。
3. **付费升级** — 软件内「系统管理 → 授权信息」点「复制申请码」发给客服，付款后粘贴授权文件即可激活，**数据不丢失**。

## 试用与授权机制

- 安装后首次启动自动进入 30 天全功能试用
